# What is robop-path-planner?

**robop-path-planner** is a curated Python code collection and reference guide for autonomous robotics and path-planning algorithms.

Features:

1. Easy to read and understand for each algorithm's foundational logic.

2. Highlights widely used, practical approaches in mobile robotics.

3. Built with minimum external dependencies.
